# ЧАСТЬ 1 — загрузить в Gemini

## Что это
Готовый комплект для обычного custom Gem: помощника по каждой отдельной песне, собственному Voice, Suno v6 и Studio 2.0.
Срез функций/условий:11 сентября2026. Библиотека: DARK_PRODUCTION_KIT_V1.

## Установка — один раз
1. Распакуй PART_1_GEMINI.zip.
2. В браузере открой https://gemini.google.com/ → Gems/Explore Gems → New Gem. Нужен обычный Gem, не mini-app/Labs workflow.
3. Название: «Мой продюсер — Suno / Dark Studio» или любое своё.
4. Открой GEM_INSTRUCTIONS.txt и скопируй ВЕСЬ текст в поле Instructions.
5. В разделе Knowledge → Add files → Upload добавь ровно шесть TXT из KNOWLEDGE:
   - 01_PROFILE_AND_SUNO_V6.txt
   - 02_PROMPTS_AND_SAMPLE_SEARCH.txt
   - 03_STUDIO_AND_IMPORT.txt
   - 04_MY_VOICE_AND_FINISHING.txt
   - 05_ASSET_CATALOG_AND_RECIPES.txt
   - 06_SESSION_PROTOCOL_AND_RIGHTS.txt
6. Нажми Save. Preview не сохраняет Gem автоматически.
7. Открой Gem и отправь CHECK_GEM_SETUP.txt. Сверь ответ с критериями в этом файле.

Не нужно загружать в Knowledge ZIP, HTML-каталог, всю WAV-библиотеку, старые версии наших баз, рецепты по одному или сам GEM_INSTRUCTIONS как седьмой knowledge-файл. Instructions уже вставлены в отдельное поле. В Knowledge уже есть каталог и текст рецептов из второй части.
Google описывает ограничения ZIP, в частности отсутствие audio/video внутри загружаемого ZIP. Оба наших архива сначала распаковываются: второй предназначен для локальной музыкальной библиотеки, не для прямого загрузочного ZIP Gemini.

## Каждая песня — отдельный чат с тем же Gem
Начни с START_NEW_SONG.txt. Заполни только известное; можно написать «BPM/key пока не знаю». Помощник спросит только критичное.
По ходу работы сохраняй SONG_PASSPORT_TEMPLATE.md в папку своей песни. Попроси «выдай актуальный паспорт». Для продолжения в новом разговоре передай последний паспорт и нужные разрешённые файлы.
Не рассчитывай на скрытую память между песнями. Одно и то же Knowledge учит общим правилам, но не заменяет паспорт конкретного проекта.

## Какие файлы куда
- GEM_INSTRUCTIONS.txt → поле Instructions Gem.
- Шесть KNOWLEDGE/*.txt → постоянное Knowledge Gem.
- Паспорт песни, скриншот, конкретный разрешённый audio-фрагмент → чат этой песни, по необходимости.
- PART_2/AUDIO/*.wav → Audio-дорожки Studio / локальной DAW.
- PART_2/MIDI/*.mid → MIDI-дорожки с инструментом; M09/M10 требуют отдельного drum mapping в DAW.
- PART_2/RECIPES/*.txt → читать/применять, НЕ импортировать как presets.
- Splice raw samples → не считать автоматически разрешёнными AI-input; правила KB06. Штатное лицензированное использование локально в DAW — отдельный путь.

## Что помощник должен выдавать
Короткое решение → где/что выбрать → файлID+путь → настройки → готовый английский prompt → проверка двух takes → запасной путь → изменение паспорта.
Это не управляющий плагин для Suno: Gemini не нажимает кнопки Studio, если у него нет фактической интеграции. Ты копируешь нужную команду в Suno Chat, предварительно выбирая объект.

## Мой Voice и приватность
Голос по умолчанию твой, уже проверенный в Suno. Имя профиля добавь в паспорт; не загружай документы личности или phrase verification в общую базу без необходимости. Короткий свой vocal для анализа — только при нужных правах и с пониманием настроек приватности Gemini.
Не делись Gem с людьми, которым не должны быть видны его Knowledge-файлы. Каталог не даёт Gemini доступа ко всему диску.

## Если что-то не загрузилось
Проверь расширение/ошибку, размер, доступность функции в аккаунте и Save. Файлы предоставлены как UTF-8 TXT для простого импорта. Не обходи ограничения добавлением audio внутрь ZIP. При невозможности сделать Gem — вставь GEM_INSTRUCTIONS в обычный чат и прикрепи релевантные TXT, сохраняя паспорт вручную.

## Важные пределы
Промпты не гарантируют безошибочного выполнения. «Естественный студийный звук» — результат отбора и ремонта, не обещание устранить любой artifact. Оригинальные музыкальные заготовки пакета2 — синтетические исходники, не живые инструменты/голоса и не готовые masters. Проверка Gemini после установки должна быть выполнена тобой — здесь в твоём аккаунте она не запускалась.
