# KB07 — Мой тембр без лишних подписок: Kits, Applio и доработка вокала
VERIFIED: 2026-09-12
COMPATIBILITY: дополнение к шести Knowledge-файлам DARK_PRODUCTION_KIT_V1.
AUDITED_LOCAL_REFERENCE: Applio 3.6.4, официальный release/tag; не произвольный main.

## 7.1. Постоянная задача пользовательницы
Цель: взять уже удачную вокальную партию песни и сделать тембр похожим на собственный голос, по возможности не перепевая всю песню. Основной рассматриваемый случай — вокал из своего Suno-проекта. Примерно одна песня в месяц. Дополнительный бюджет — по возможности ноль. Обновление пользовательницы: Windows x64, RTX 3050 Laptop GPU с 4 GB VRAM, RAM 32 GB, i5-12500H. Драйвер неизвестен; датасет нужно записать с нуля. Состояние микрофона и следующий тест см. в CURRENT_STATE паспорта.
Сохраняются: Premier, собственный Voice, русский язык, dark art-pop/darkwave, поэтичный indie/post-punk, industrial-organic trip-hop. Не менять жанры на rap/phonk/radio dance-pop. Блок про новые темы/тренды стихов пользовательница решила отложить.

Рекомендация под эти условия:
1. Если свой Voice внутри уже оплаченного Suno даёт нужный результат — не покупать второй сервис только ради наличия сервиса.
2. Для регулярной внешней voice-to-voice работы без новых подписок рассмотреть Applio локально: разово собрать свои реальные записи, обучить собственную модель, далее конвертировать разрешённые источники этой моделью.
3. Перед именно Suno Output → другой AI-конвертер пройти gate прав в §7.3. Техническая возможность не равна разрешению по договору.
4. Kits/Audimee — удобные облачные варианты, но Free не решает бесплатно полный цикл со своим клоном и нужным экспортом.
5. Минимальный стек: Suno Studio (уже оплачен) + Applio; UVR только при необходимости изоляции; Audacity для бесплатного локального редактирования. Плагины добавлять по проблеме, не все сразу.

Это подбор по бюджету и workflow, а не независимый рейтинг качества голосов. Конверсии/обучение на её записях здесь не выполнялись. Наличие NVIDIA ещё не доказывает, что выбранная конфигурация обучения поместится в память.

## 7.2. Разовая модель и новая песня — разные задачи
| Процесс | Вход | Выход | Как часто |
|---|---|---|---|
| Training / voice cloning | Настоящие сухие записи пользовательницы | Модель её тембра | Обычно разово, затем улучшения по необходимости |
| Inference / voice conversion | Готовая сольная вокальная партия + модель | Новое аудио в целевом тембре | Для каждой новой партии/варианта |
| Pitch correction | Вокал с неверными нотами | Исправленная высота/переходы | Только где нужно |
| Cleanup / de-essing | Шум, резкие согласные, дефекты | Более чистое аудио | По проблеме |
| Mixing | Уже пригодная партия в аранжировке | Согласованный финальный микс | Для каждой песни |

Разово записать материал для модели НЕ означает разово вычислить все будущие песни. Но в локальной программе новые конверсии не требуют платы сервису за каждую минуту или активной подписки. Остаются затраты времени, электричества, хранения и уже имеющегося оборудования.
Voice conversion в основном меняет тембр. Она может унаследовать неправильные слова, ударения, ноты и ритм источника, а также добавить собственные артефакты. Не считать её гарантированным редактором фонем или «оживителем» любой плохой генерации.

Важно различать:
- TRAINING DATA = мои реальные записи, из которых учится модель.
- CONVERSION INPUT = готовая партия с нужной мелодией и подачей, которую преобразуем.
- TARGET MODEL = обученный собственный голос.
- OUTPUT = новый вокальный файл, который нужно проверить и вернуть в проект.

Suno Voice-профиль, Kits-профиль и Applio .pth — разные системы. Не обещать перенос одного профиля в другую систему простым скачиванием/переименованием. Исходные свои записи можно сохранить для подготовки моделей в разных системах, если нужные права имеются.

## 7.3. Gate прав: обязательно до внешней AI-конверсии
### Свои реальные записи
Обучать локальную модель на собственном настоящем голосе и материале, которым пользовательница вправе распоряжаться. Не брать чужого артиста, вокал из Splice, случайный public model или синтетический Suno Voice как замену реальному личному датасету.

### Suno Output — не считать автоматически разрешённым AI-source
В проверенной редакции Suno Terms раздел Conditions of Access and Use, пункт 10 содержит широкое ограничение на использование Services, Output и Voice Model для конкурирующих продуктов и для power/enable/train других AI/ML models, tools or technologies. В разделе Permitted Commercial Use одновременно предусмотрены разрешённые download и обычное edit/process/format conversion, но это само по себе не является ясным отдельным разрешением именно сторонней AI voice conversion.
Поэтому статус для индивидуального Suno lead → Kits/Applio inference не отмечать как «разрешено, потому что Premier». Это вопрос, который следует уточнить у Suno. Не давать ни юридической гарантии, ни уверенного расширительного толкования, будто любой внешний аудиоредактор запрещён. Готовый вопрос — в SUPPORT_QUESTIONS.txt.
Технический маршрут ниже применять к источнику, для которого нужные права/разрешения установлены. Для пробной локальной конверсии можно начать со своих настоящих записей. Нативный Suno Voice и обычный разрешённый монтаж/DSP остаются отдельными маршрутами.
На Suno Output нельзя автоматически обучать внешнюю голосовую модель. В этом дополнении training основан только на реальных собственных записях.
Источник: [1](https://suno.com/terms).

### Splice и другое стороннее аудио
Сохраняются ограничения KB06. Стандартные Splice Sounds запрещены как source/training material для AI-моделей. Локальный запуск Applio/UVR не превращает такой источник в разрешённый: local AI тоже AI. «Бесплатная программа» и «разрешённый материал» — разные вопросы.
Если в миксе есть такие sounds, не отправлять его автоматически в AI-isolator/voice changer. Проверить лицензию и intended use; для неясного случая — отдельное разрешение. Обычный локальный монтаж/традиционный DSP отличается от AI-инференса.
Источник: [2](https://splice.com/terms).

Нужны три независимые проверки: право на training data; право на conversion input; лицензия кода/базовых весов/сервиса и право использования output. Ничего не снимать/не обходить ради маскировки происхождения. Не записывать player как обход платного download.

## 7.4. Kits AI: что на скриншоте и что реально оплачивается
На скриншоте выбор Instant Voice Cloning и Professional Voice Cloning. Для готовой песни после создания голоса нужен Voice Changer / Convert, а не Generate Vocals по новому тексту.

### Instant против Professional
- Instant: ориентир примерно 30 секунд референса (Help также пишет 15–30 сек). Быстро, но сама Kits предупреждает, что метод не оптимален для high-fidelity и высокой похожести.
- Professional: в Help ориентир 15–30 минут; та же статья ниже рекомендует 10–60 минут dry monophonic vocals. Это не одна жёсткая универсальная граница, а рекомендации к разным сценариям. Практически сначала готовить качественные 15–30 минут своих записей, а не добавлять шум ради длины.
- Professional training по оценке Kits может занимать от 30 минут до нескольких часов. Это оценка провайдера, не измерение на нашем материале.
- «Exact match» в рекламной формулировке не обещать пользовательнице как гарантированный результат.
[1](https://help.kits.ai/hc/en-us/articles/40742972060435-How-is-Instant-Voice-Cloning-different-from-Professional-Voice-Cloning)
[1](https://help.kits.ai/hc/en-us/articles/25367001343635-What-is-Professional-Voice-Cloning)

### Проверенный публичный тарифный снимок, USD
| План | Видимая месячная цена | Download | Вывод для одной песни |
|---|---:|---:|---|
| Free | $0 | 0 download minutes | Проба сервиса, не бесплатный полный собственный vocal-export workflow |
| Starter | $10/month | 15 min/month,2 voice slots | Потенциально достаточно объёма для одной песни; проверить включённый тип cloning |
| Producer | $30/month | 60 min/month,unlimited slots по странице | По FAQ поддерживает Instant+Professional; не покупать автоматически ради одной песни |
| Professional | $60/month | unlimited с fair use | Для заданного объёма обычно избыточен |

На pricing есть внутреннее расхождение: карточка Starter перечисляет Professional Voice Cloning, а FAQ/Help описывают Starter через Instant и Professional явно называют в Producer. Также у Free карточка и FAQ расходятся по voice slots. Не замалчивать расхождение и не объявлять $30 обязательным минимумом, когда карточка упоминает $10. Для оплаты запросить подтверждение актуального entitlement в аккаунте/checkout/поддержке. Free по проверенной FAQ не предоставляет Instant/Professional cloning и не даёт downloads — для нашего решения этого достаточно.
Цены для новых пользователей; старые аккаунты могут сохранять прежние условия. Налоги/валюта/годовая скидка проверяются перед оплатой. Не брать $14.99/$24.99 из старого blog/JSON-LD как текущую цену новой подписки, если страница говорит иначе.
[1](https://www.kits.ai/pricing)
[1](https://help.kits.ai/hc/en-us/articles/25450515542291-Which-plans-do-you-offer)

### Самый важный ответ про отмену
- Модели после отмены не удаляются, но становятся недоступны до возобновления подписки.
- Доступ к платным функциям сохраняется до конца оплаченного периода.
- Накопленные download minutes теряются, когда подписка истекает.
- При последующей подписке сгоревшие минуты не возвращаются.
- Уже сохранённый WAV на своём диске и дальнейший доступ к cloud-модели — не одно и то же. Перед окончанием периода сохранить нужные результаты и сведения о правах.
[1](https://help.kits.ai/hc/en-us/articles/25498080455187-What-happens-to-my-custom-trained-AI-voice-models-if-I-cancel-my-subscription)
[1](https://help.kits.ai/hc/en-us/articles/28297197996051-What-happens-to-my-download-minutes-after-I-cancel-my-subscription)

Не обещать схему «один месяц обучила — потом бесплатно конвертирую каждый месяц своим Kits-клоном». Штатный перенос Kits-trained model в Applio не подтверждён. Статья Kits про .pth upload НЕ доказывает возможность скачать их proprietary trained model. Уточнять export/совместимость отдельно.
Kits разрешает использование outputs собственных trained models при наличии прав на использованный материал; это не даёт прав на запрещённый upstream source. [1](https://help.kits.ai/hc/en-us/articles/25539059275155-What-can-I-do-with-the-output-of-MODELS-THAT-I-TRAINED)

## 7.5. Kits: рабочий процесс без ненужных генераций
1. Проверить права и платные функции до оплаты.
2. Подготовить own-voice reference/dataset, создать подходящий clone.
3. Для готовой партии открыть Voice Changer (Kits Studio).
4. Подать WAV/MP3 сольного lead; lossless WAV предпочтительнее дополнительного MP3-перекодирования.
5. Выбрать созданный собственный target voice.
6. Сделать тест 20–40 секунд с гласными, согласными и переходами.
7. Подобрать настройки, сравнить варианты в player; скачивать нужный final, а не каждую длинную неудачу.
8. Сохранить full vocal без ненужной обработки и вернуть его на отдельную Audio-дорожку в Suno/DAW, проверив origin/timing.
[6](https://help.kits.ai/hc/en-us/articles/45057016270611-Voice-Changer-Kits-Studio)

В этом workflow нет обязанности писать «стилевой промпт» как в Suno. Kits Style/Strength — параметр преобразования, не текстовое поле Suno Styles. Gemini должен выдать список input/target/settings/действий, а не придуманный универсальный текст, который некуда вставлять.

### Похожесть и русская дикция могут конфликтовать
Kits советует повышать Style/Strength для похожести на target. Для non-English pronunciation и части artifacts Help, наоборот, предлагает уменьшить Style/Accent Strength. Это trade-off, а не противоречие, которое решается «всегда 100%».
- Голос недостаточно похож: проверить target/dataset, затем отдельный тест Style выше.
- Согласные/дыхание роботизируются: отдельный тест Strength ниже, чистота source и similarity training audio.
- Не переключать сразу все ручки; сохранить исходный good take.
- Названия Style/Accent Strength зависят от интерфейса/legacy controls. Если их нет — не выдумывать местоположение.
[1](https://help.kits.ai/hc/en-us/articles/32357276455571-How-do-I-make-my-voice-change-outputs-sound-more-like-the-target-voice)
[1](https://help.kits.ai/hc/en-us/articles/29234378414355-I-have-a-non-English-accent-and-my-changed-voice-doesn-t-sound-right-How-do-I-fix-it)
[1](https://help.kits.ai/hc/en-us/articles/25881322198803-How-do-I-reduce-artifacts-in-my-voice-changer-and-voices)

## 7.6. Бесплатный локальный путь: Applio
Applio — open-source suite для RVC-style voice conversion/training; у проверенного release 3.6.4 код под MIT. Локальное использование не требует ежемесячной подписки провайдеру. Cloud deployment/аренда GPU — другой сценарий и не обещаются бесплатными.
Сайт рекомендует NVIDIA RTX 20-series или новее для хорошего training experience. Это рекомендация, не доказательство, что любая NVIDIA подходит любой конфигурации. Для inference обычно требования ниже, чем для обучения.
[8](https://applio.org/)
[7](https://github.com/iahispano/Applio)
[1](https://github.com/IAHispano/Applio/blob/3.6.4/LICENSE)

### До установки — hardware gate
Попросить:
- точное имя GPU;
- Dedicated GPU memory / VRAM;
- RAM;
- Windows version;
- сколько свободного места;
- готов ли собственный чистый вокальный dataset.
В Windows: Ctrl+Shift+Esc → Performance → GPU; нужны имя и выделенная память, не серийные номера/учётные данные. При нескольких GPU выяснить, какая NVIDIA будет использоваться.
Не назначать batch size, GPU-патчи, CUDA/PyTorch-команды или время training, пока железо неизвестно. Для RTX 50-series особенно важна совместимость сборки/драйвера; не применять старые советы CUDA из случайного видео.

Официальная installation guide предлагает precompiled ZIP из официального Hugging Face репозитория, распаковку в простой доступный путь без пробелов/спецсимволов и запуск run-applio.bat.
Проверенный release 3.6.4 от 27 июля 2026:
https://github.com/IAHispano/Applio/releases/tag/3.6.4
Официальная документация:
https://docs.applio.org/getting-started/installation/

Использовать ссылки из официального релиза, не чужие перепаковки. Не запускать installer от администратора без конкретной необходимости. Не отключать антивирус/файрвол целиком — даже если подобный совет присутствует в release-note. При блокировке остановиться, проверить источник/подпись/сообщение защиты, а не обходить всё подряд.
Для первого сценария нужен offline file conversion, НЕ Realtime, виртуальный аудиокабель, Discord-routing или публичный share URL. Обычная локальная web-страница Applio открывается на собственном компьютере; это не облачная модель и не окно Suno.
Первая установка/получение embedders/pretrained weights требует загрузок. Не обещать «никогда никакой сети» для всех дополнительных plugins/cloud/TTS options. Не включать public sharing/auto-upload своих моделей.
Скачивание/установка/обучение на компьютере пользовательницы здесь не выполнялись.

## 7.7. Разовая запись своего датасета
Официальный ориентир Applio:10–30 минут чистого lossless audio. Для нашего singing-сценария основа — собственное сухое пение, не чужая акапелла и не output Suno. Хорошие 10 минут полезнее 30 минут шума.
[1](https://docs.applio.org/getting-started/training/)
[2](https://docs.applio.org/guides/how-create-datasets/)

Практический план записи, не обязательный норматив:
- 4–6 минут спокойного пения в удобном среднем регистре;
- 3–5 минут фраз с разными русскими гласными/согласными;
- 2–4 минуты устойчивых длинных нот и естественных переходов;
- 2–4 минуты более тихой/эмоциональной манеры, которая реально нужна в песнях;
- при необходимости ещё материал верхнего/нижнего удобного регистра, без форсирования.
Это должна быть длительность полезного материала, не 20 минут с большой тишиной.

Запись:
- тихая комната, минимум отражений;
- одна вокальная линия; monophonic не равно просто mono-channel: хор, сведённый в mono, всё ещё несколько голосов;
- без instrument bleed, chorus, doubles, reverb и сильного autotune;
- не клиппировать; в исходной записи оставить запас;
- WAV/FLAC, реальная достаточная частота записи; смена 16-bit → 24-bit не восстанавливает потерянный сигнал;
- сохранять raw originals и отдельно prepared copy;
- убрать кашель, посторонние звуки, чрезмерно шумные участки и длинные провалы;
- не срезать все естественные дыхания/начала согласных и не обрабатывать dataset до «пластика»;
- не подбирать training data исключительно из шёпота, если нужны и нормальные певческие фразы.

Можно использовать имеющиеся свои качественные raw-записи. Не обязательно каждый месяц снова записывать 10–30 минут. Но при нехватке диапазона/манеры один раз расширить датасет разумнее, чем каждый раз чрезмерно выкручивать inference.

Важное разделение: dataset можно нарезать и убирать длинную тишину для обучения; SOURCE ПЕСНИ перед conversion нельзя автоматически Truncate Silence — иначе разрушится timing относительно аранжировки.

## 7.8. Обучение модели — не перепутать файлы и этапы
Общая последовательность Applio:
1. Own dataset → pre-processing.
2. Pitch/features extraction; RMVPE рекомендован в training guide.
3. Совместимые model settings: sample rate, vocoder, embedder, pretrained G/D.
4. Training с сохраняемыми checkpoints.
5. Index generation, если используется retrieval.
6. Экспорт inference-модели и соответствующего index.
7. Тест на отложенной фразе, не только на training audio.
[1](https://docs.applio.org/getting-started/training/)

Названия кнопок и автоматизация отдельных шагов могут отличаться. Не обещать, что каждый release имеет одну и ту же последовательность экранов. Не выбирать sample rate/vocoder по принципу «максимальное число лучше». Конфигурация и pretrained должны совпадать; embedder при inference — тот же, что при training.

Training guide приводит 200–400 epochs как стартовый ориентир и предлагает сохранять checkpoints. Это НЕ обещание оптимума для любого датасета. Число epochs не равно числу steps, а минимальный g/total loss не является измерением слухового сходства. Сравнивать checkpoints на одинаковом test excerpt. Batch подбирать по фактическому VRAM; при CUDA OOM уменьшить нагрузку и проверить совместимость, а не отключать защиту компьютера.

| Файл / объект | Куда относится | Куда НЕ загружать |
|---|---|---|
| Own raw WAV | Подготовка training data | Не выдавать за уже обученную модель |
| Exported inference .pth | Applio model selector | Не на Audio/MIDI track Suno и не в Wavetable |
| Matching .index | Applio retrieval index | Не перемешивать с index другого голоса |
| Training G/D checkpoints | Возобновление/экспорт training, по формату | Не считать любой G/D файл готовой inference-моделью |
| Suno Voice profile | Внутренняя функция Suno | Не обещать автоматически скачать как Applio.pth |
| Kits custom voice | Kits cloud profile | Не считать .pth upload-статью доказательством export |
| Converted WAV | Audio track в Studio/DAW | Не использовать как пресет/индекс |

Файл .pth обязателен для inference. Index рекомендуется, но retrieval может быть отключён; отсутствие index не повод подставлять index чужого голоса. При работе без него явно зафиксировать этот режим.

В дополнении нет .pth/.index собственного голоса: без реальных записей и training их не создавали. Не переименовывать WAV в .pth. Не загружать голосовые веса в Knowledge Gemini: обычно достаточно метаданных/паспорта.
Делать backup собственных originals, exported model, index, training config/версии и удачных результатов. Не удалять старую папку Applio при обновлении до проверки backup. Осторожно с неизвестными checkpoint: модельные файлы не следует считать безопасными просто из-за расширения.

## 7.9. Applio inference: проверенные поля и разумный первый тест
Референс ниже привязан к исходному коду release 3.6.4. Это проверка определений/условий кода, НЕ результат испытания голоса пользовательницы.

| Поле | Диапазон/значение в 3.6.4 | Начальный смысл |
|---|---|---|
| Export Format | WAV выбран по умолчанию | Выгружать рабочий lossless файл, не цепочку MP3 |
| Pitch | -24…24semitones; default0 | Сохранить исходные ноты; положительное повышает, отрицательное понижает |
| Search Feature Ratio | 0…1; default0.75 | Влияние index; более низкое иногда уменьшает artifacts |
| Volume Envelope | 0…1; default1 | 1 — output envelope; ближе 0 — больше следования source dynamics |
| Protect Voiceless Consonants | 0…0.5; default0.5 | См. уточнение алгоритма ниже, не доверять одной подписи |
| Pitch extraction algorithm | rmvpe / crepe / crepe-tiny / fcpe; default rmvpe | Для baseline — rmvpe и совместимый training/model |
| Split Audio | defaultOff | На коротком test не добавлять лишние стыки |
| Autotune | defaultOff | Сначала не менять уже удачную мелодию дополнительной коррекцией |
| Clean Audio | defaultOff | Не включать сильную очистку без необходимости |
| Formant Shifting | defaultOff | Не менять форманты/личность вслепую |
| Post-Process | defaultOff | Сначала оценить саму конверсию без Reverb/Chorus/Distortion |

Проверенные исходники:
[1](https://github.com/IAHispano/Applio/blob/3.6.4/tabs/inference/inference.py#L591-L686)
[1](https://github.com/IAHispano/Applio/blob/3.6.4/tabs/inference/inference.py#L1046-L1123)

### Важное исправление по Protect
Документация и tooltip не полностью согласуются с runtime-кодом 3.6.4. В pipeline, при pitch guidance, дополнительное смешивание исходных features на unvoiced участках включается только при protect<0.5. Чем меньше это значение в этой ветке, тем больше сохраняется исходного feature-содержимого на таких участках; при 0.5 именно это дополнительное смешивание не выполняется.
Эффект также зависит от наличия retrieval/index и pitch guidance.
Поэтому НЕ давать универсальное «чем выше Protect, тем больше защиты» для этого release и НЕ назначать 0.7: оно вне диапазона UI3.6.4.
Практический отдельный тест: default0.5 против 0.33 на одном коротком source, всё остальное одинаково. При необходимости ещё 0.2. Это гипотезы для слухового сравнения, не «правильные настройки для всех».
[1](https://github.com/IAHispano/Applio/blob/3.6.4/rvc/infer/pipeline.py#L334-L361)

### Ещё две ловушки старых инструкций
- В prose inference-doc встречается перепутанный пример направления octave shift. Не использовать gender→±12 как автоматическое правило. Выше Pitch — выше высота; baseline0; согласовать диапазон с собственной моделью и музыкальной задачей.
- Filter Radius встречается в общей документации, но в проверенном inference UI-файле 3.6.4 этого поля нет. Не заставлять пользователя искать несуществующую ручку или выдавать default3 как реально показанную настройку именно этой версии.

### Первый запуск
1. Установить права на source и наличие собственного target model.
2. Выбрать exported .pth + matching .index; тот же embedder/model configuration.
3. Загрузить один тест 20–40 секунд, не сразу все 4 минуты.
4. Снять лишние post-effects, Pitch0, остальные поля сначала baseline.
5. Convert → прослушать отдельно и с аккомпанементом.
6. Один параметр на вариант; держать список A/B и имена файлов.
7. Только после выбора параметров обрабатывать полный lead.

Не нужно писать английский paragraph в воображаемое поле «Style» Applio. Gemini выдаёт карту настроек/файлов/кнопок. Если UI новой версии отличается — запросить скриншот и пересверить текущий release.

## 7.10. Ежемесячный workflow: из хорошей партии в свой тембр
Техническая схема применяется после gate прав к конкретному source.

1. Выбрать хороший original lead: правильные слова, ноты, phrasing и timing.
2. Сохранить original song/reference и исходный vocal файл.
3. Если требуется изоляция — сравнить имеющийся Suno lead stem и допустимый local separator, например UVR. Не делать пять passes подряд без причины; separation может добавить артефакты.
4. Для conversion нужен преимущественно один голос, без большого room/reverb, choir и инструментов. Стереоконтейнер с одним lead и mono-файл с хором — не одно и то же.
5. Готовить dry source. Не исправлять плохую дикцию только converter. Не удалять начальную тишину/паузы, нужные для таймлайна.
6. Конвертировать короткий test собственной моделью; затем whole lead.
7. Вернуть converted WAV на новую Audio-дорожку того же проекта с тем же временным origin.
8. Сравнить начало, середину и конец: инструмент может подрезать края, изменить длительность или дать задержку. Выравнивать по реальному аудио, не просто по красивому имени файла.
9. Отключить старый lead, если он не должен играть. Не смешивать случайно original+converted и принимать фазовый chorus за «похожесть».
10. FX/volume automation после конверсии: gain, мягкий EQ/compression, нужное пространство. Хорошая dry conversion полезнее изначально залитой reverb.
11. Плохой слог — другой take/локальный repair/свой punch-in. Не конвертировать выход конвертера снова бесконечной цепочкой.
12. Архивировать source, output, model/index version, settings и результат A/B. Следующую песню начинать с той же рабочей модели, но не с чужих BPM/key/notes.

Для бэков и гармоний: по возможности отдельные партии/диапазоны. Один monophonic converter может плохо справиться с готовым хором. Если лишний слой не улучшает песню — его можно не добавлять.

## 7.11. Что именно сравнивать на коротком тесте
- Сходство с реальным approved собственным голосом, а не только со stock voice.
- Сохранены ли melody/timing/dynamics, которые нравились в source.
- Русские С/Ш/Щ/Т/Ч, переходы в гласные, начала/концы слов.
- Длинные гласные: нет ли wobble, metallic shimmer, случайных скачков октавы.
- Дыхание: естественное/слишком шумное/роботизированное.
- Регистровые переходы, фальцет, тихие фразы.
- Что слышно в solo и что слышно в mix.
- Сравнимая громкость: громче не означает больше похожести.

Удачная конверсия может быть достаточно похожей, но всё ещё не имитировать реальное исполнение пользовательницы полностью: мелодическая манера источника сохраняется. Это не запись того, как она сама целиком спела именно эту песню.
Gemini не может оценить likeness по имени модели или одному screenshot. Нужен доступный разрешённый audio/reference либо конкретный отзыв пользовательницы; заявления о прослушивании и измерениях должны соответствовать фактическому доступу.

### Какой минимальный набор выбрать сейчас
Не ставить всё сразу. Для своей локальной модели — Applio. Для подготовки записей — при необходимости Audacity. Для изоляции — UVR только если исходный lead недостаточно чистый. Для возврата в песню — уже имеющийся Studio. T-De-Esser/Graillon/Bertom добавлять только при конкретной проблеме и наличии совместимого host. VST/AU не импортируются в Suno Studio.

### UVR
Официальный сайт: [1](https://ultimatevocalremover.com/). Брать приложение из официального GitHub/release по ссылке сайта. Нельзя считать бесплатность программы разрешением на обработку любого source. Не выбирать бесконечное число ансамблей моделей вместо сравнения пары конкретных результатов.

### Audacity
Официальная noise reduction работает прежде всего со стационарным hiss/hum/fan noise и требует noise-only sample. Агрессивная обработка сама даёт watery/warbling artifacts. Для training dataset сначала source quality, не extreme cleanup. Truncate Silence применимо к подготовке датасета, но не автоматически к source партии, который должен остаться выровнен по времени.
[1](https://www.audacityteam.org/features/noise-reduction/)

### T-De-Esser2
Free VST/VST3/AU/AAX по платформе; Windows VST3 для совместимого редактора, не для Suno plugin slot. Производитель разрешает personal/commercial audio use, но не свободную перепаковку installers. В нашем архиве только инструкция/ссылка, не чужой installer.
Начать с прослушивания Filter и выбора range, затем мягко Processing/Intensity; проверять Diff, чтобы не убирать тело/дикцию. Не принимать рекламное artifact-free за гарантию.
[1](https://techivation.com/t-de-esser/)

### Bertom Denoiser Classic
Free/PWYW, Windows VST3/AAX; нужен host. Традиционный noise-reduction workflow, не новый голос. На clean source его не нужно включать для галочки.
[3](https://bertomaudio.com/denoiser-classic.html)

### Graillon3 Free
Pitch/formant/correction инструмент. Для сохранения мелодии source не включать aggressive hard-tune по умолчанию. Не применять смену формант вместо настоящего own-voice model и не обещать восстановление всех слов.
[1](https://www.auburnsounds.com/products/Graillon.html)

### REAPER
Текущая покупка: discounted$60 при личном использовании/соответствующейвыручке/учебнойнекоммерческой eligibility; commercial$225. 60-dayevaluation; цены безналогов. Это дополнительная one-time альтернатива постоянным audio-subscriptions, не покупка, которую нужно совершить сейчас.
[1](https://www.reaper.fm/purchase.php)

### LALAL.AI
Текущая FAQ: Lite — $9.99/month либо $90/year; Pro — $19.99/month либо $180/year. На странице по умолчанию могут отображаться годовые эквиваленты $7.5/$15 в месяц.

Free Starter: 10 минут для preview; скачивание полного результата не предоставляется. Fast/Relaxed — разные очереди. Fast minutes сбрасываются и не переносятся на следующий период.

Не повторять из старых гайдов «одна покупка минут навсегда» без проверки: текущая страница описывает подписки и Top-Ups. Local/VST вариант также не означает автоматически разовую бесплатную лицензию.
[3](https://www.lalal.ai/)

## 7.14. Экономика одной песни в месяц
Пусть lead длится 4 минуты. Это иллюстрация, а не установленная длина песни пользовательницы.

**Kits Starter:** три разных скачанных версии по 4 минуты = 12 download minutes, что укладывается в 15 при прочих условиях плана. Платные конверсии заявлены unlimited с fair use, но downloads ограничены. Не предполагать без проверки, как учитываются повторное скачивание и разные форматы одного результата.

Если платить $10 каждый месяц, 12 месяцев = $120 до налогов. Для $30 это $360. Это арифметика месячного тарифа, не рекомендация покупать подписку.

Один оплаченный месяц для обработки нескольких УЖЕ готовых партий может быть удобен. Но это не решает обработку ещё не созданных песен будущих месяцев. После окончания периода Kits закрывает доступ к модели; накопленные минуты сгорают.

**Applio:** разовая подготовка/обучение, затем локальные конверсии. Плата сервису — $0, но время, электричество, хранение и оборудование не становятся бесплатными. Если GPU не подходит, не обещать нулевую стоимость покупки другого компьютера.

Самый дешёвый первый шаг при уже имеющемся Premier — оценить собственный Voice Suno и нужную локальную обработку без новой подписки. Внешнюю AI-конверсию Suno Output рассматривать после уточнения прав.

Для любого платного предложения Gemini сначала выясняет:
- Что оплачивается: training, conversion или download?
- Доступен ли собственный clone именно на этом плане?
- Какова полная цена одного месяца, а не annual equivalent?
- Нужна ли карта для trial и когда будет списание?
- Что остаётся после отмены: сохранённые файлы, model access, credits?
- Есть ли отдельный pay-as-you-go или только Top-Up поверх плана?
- Какие права нужны на source и commercial use?

Не покупать, не запускать trial и не отправлять письма от имени пользовательницы без отдельного разрешения.

## 7.15. Правила для Gemini: интеграция с прежней базой
1. Различай собственный Suno Voice, Applio-trained own voice, Kits cloud clone и обычную pitch/FX-обработку. Не переносить регуляторы одной системы в другую.
2. Бюджет дополнительного сервиса по умолчанию — 0. Известны Windows и NVIDIA; GPU и VRAM уже известны из актуального паспорта; драйвер пока неизвестен.
3. Для локальной установки запроси GPU, VRAM/RAM и состояние датасета. Не назначай точную training-конфигурацию вслепую.
4. Сначала gate прав. Для Suno Output → сторонний AI не утверждай разрешение лишь по факту Premier. Используй SUPPORT_QUESTIONS и условный технический маршрут.
5. Training — только на собственных реальных записях. Voice weights/index не загружаются как Gemini Knowledge, Suno Audio или Wavetable preset.
6. Для Kits/Applio выдавай карточку input, target, settings, action, output, QC. Не выдумывай поле текстовых Styles там, где нужны файлы и числовые регуляторы.
7. Не обещай бесплатный рабочий Kits-export, доступ к клону после cancel, возвращение сгоревших минут или экспорт облачной модели в RVC без подтверждения.
8. Применяй code-audit 3.6.4 только к согласованной версии. Не давать Protect 0.7, не путать знак Pitch и не заявлять, что максимум Protect включает максимум дополнительного смешивания исходных features в этой реализации.
9. Не советуй глобально отключать антивирус/файрвол, скачивать случайные .exe/.pth или включать public sharing личного голоса.
10. Не считать голос успешно клонированным по названию профиля. Заявлять о действиях, прослушиваниях и измерениях только при фактическом доступе.
11. Музыкальный PART_2 с 70 IDs остаётся без изменений. В нём нет модели её голоса. Для персонального голосового процесса вести отдельный VOICE_STATE.
12. Темы и тренды стихов пока отложены. Применять существующую практику Lyrics из KB02/04 можно, но новый ресерч не выдумывать.

Формат короткого ответа:
Задача → разрешённый source/статус прав → лучший бесплатный маршрут → что установлено и чего ещё нет → input/target → настройки одной пробы → критерии сравнения → fallback → VOICE_STATE_DELTA.

## 7.16. VOICE_STATE — расширение паспорта песни
- song_id
- requested_route: Suno-native / Applio-local / Kits / Audimee / traditional-DSP
- source_origin: real-own-recording / Suno-output / third-party / unknown
- source_rights_for_external_AI: confirmed / clarification-needed / not-permitted / unknown
- source_filename / vocal-only / wetness / timing_origin
- target_voice_owner: myself
- own_dataset_status / clean_audio_minutes / training_data_rights
- gpu_model / vram / ram / driver / app_version
- model_file / matching_index / model_sample_rate / embedder / vocoder
- selected_checkpoint / why_selected
- inference_parameters / test_excerpt
- output_filename / actual_duration / alignment_checked
- likeness / diction / pitch / artifacts / dynamics / mix_result
- cloud_plan / monthly_or_annual / download_minutes / expiration_if_known
- current_extra_budget
- approved_variant / next_one_action

Шаблон не создаёт реальные файлы модели. Unknown — допустимое значение. Вне доступного чата не обещать надёжную память: выдавать актуальный паспорт для сохранения.

## 7.17. Следующий конкретный шаг
Существующий Gem и новую песню можно продолжать использовать. Обновлённый этап: GPU — RTX 3050 Laptop 4 GB, RAM 32 GB; готовых записей для датасета пока нет. Сейчас нужна короткая raw-запись имеющимся микрофоном. После её проверки — подготовка датасета, свободного места и локальной установки. Не повторять уже отвеченные вопросы о GPU и наличии датасета.

После этого — одна короткая проба, а не покупка трёх подписок.
