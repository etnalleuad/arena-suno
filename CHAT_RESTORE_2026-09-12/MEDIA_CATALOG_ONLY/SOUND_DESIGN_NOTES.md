# Технические заметки

48kHz/PCM24 WAV, TPDF dither на записи; умеренный запас по пикам. Синтез: decaying sine/FM/additive tones, шум с полосовой фильтрацией, короткие envelopes, композиция событий; никаких скачанных чужих recordings.
Stereo loops имеют распределение голосов/событий, басовые основы — mono. Все clips с корректными числовыми значениями и контролируемыми крайними samples; художественную петлю нужно оценить на реальном проекте.

MIDI: Standard MIDI File Type1,480PPQ, tempo/time signature; melodic files имеют key metadata, drum MIDI — без тональности. Channel10 для M09/M10; остальные melodic на channel1. Program Change не навязывается — инструмент выбирается в проекте.

L03 ↔ M02, L04 ↔ M01, L08 ↔ M04, L09 ↔ M03, L10 ↔ M07, L11 ↔ M05, L05 ↔ M06. WAV-render имеет собственные envelopes/timbre; ноты MIDI позволяют выбрать другой инструмент. Созданный MIDI-to-audio cover в Suno может интерпретировать источник иначе.

S01/S02/S03 — обычные суммы/аранжировки синтетических частей, без вокала и без внешнего AI-генератора музыки. Они предназначены для иллюстрации палитры и распределения ролей, не для заявления «готовая студийная песня».

Полный источник построения пакета сохранён в рабочей папке диалога. Каталог содержит SHA256 каждого медиа/recipe файла для проверки согласованности имён и содержимого.
